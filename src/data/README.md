# 项目展板数据

- `projects.json`：个人项目，保留现有格式。
- `research.json`：科研成果，按数组顺序展示。当前为空，页面显示「相关成果整理中」。

两个栏目默认各显示数组中的前 4 项；超过 4 项时出现展开／收起控件，并显示剩余数量。要调整默认展示的工作，直接调整相应数组顺序。

科研成果的必填字段为 `title` 和 `description`。其他字段均可省略：

| 字段 | 内容 |
| --- | --- |
| `titleEn` / `descriptionEn` | 英文标题与简介；未填写时沿用中文 |
| `authors` | 作者列表，可直接标明自己的名字与贡献标记 |
| `venue` / `year` | 期刊、会议或项目名称 / 年份（数字） |
| `paperUrl` | 论文链接 |
| `githubUrl` | GitHub 仓库链接 |
| `projectUrl` | 科研项目主页 |

链接填写完整的 HTTPS 地址。未填写的链接不显示按钮，可只放论文、只放仓库，或同时展示三种入口。只添加已确认的科研经历和成果。
